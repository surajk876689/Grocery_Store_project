4. CHECKOUT FLOW (WITH STOCK VALIDATION)
================================================================================

  [User clicks "Checkout"]
          |
          v
  < Cart is empty? >
          |        |
         YES       NO
          |        |
          v        v
  [Show "cart   [Set processing = true]
  is empty"     [Disable checkout button]
  message]              |
                        v
              [POST /checkout to backend]
              {
                customer_name: "...",
                items: [{item_id, quantity}, ...]
              }
                        |
                        v
              ┌─── BACKEND PROCESSING ───┐
              │                          │
              │  < Cart empty? >         │
              │    YES → 400 EmptyCart   │
              │                          │
              │  For each item:          │
              │  [Lock DB row]           │
              │  < Item exists? >        │
              │    NO → 404 NotFound     │
              │  < qty > stock? >        │
              │    YES → 409 Conflict    │
              │  [Deduct stock]          │
              │  [Add to receipt]        │
              │                          │
              │  [db.commit()]           │
              │  [Return receipt JSON]   │
              └──────────────────────────┘
                        |
              ┌─────────┴──────────┐
             SUCCESS             ERROR
              |                    |
              v                    v
  [recordPurchase()         [Show error message]
   → update AI history]     [Re-enable button]
              |
              v
  [clearCart()]
              |
              v
  [navigate('/receipt', { state: receipt })]
              |
              v
  [Show ReceiptPage with itemised totals]

8. AI SMART SEARCH FLOW
================================================================================

  [User types in search box]
          |
          v
  [useDebounce waits 150ms]
          |
          v
  [debouncedQuery updates]
          |
          v
  [rankItems(items, query) called]
          |
          v
  [For each item, calculate score:]

  ┌──────────────────────────────────────────────┐
  │  query = query.toLowerCase()                 │
  │  name  = item.name.toLowerCase()             │
  │                                              │
  │  score = 0                                   │
  │                                              │
  │  < name === query >      → score += 100      │
  │  < name.startsWith(q) >  → score += 60       │
  │  < name.includes(q) >    → score += 30       │
  │  < fuzzyMatch(name, q) > → score += 10       │
  │                                              │
  │  boost = min(purchaseCount[item.id] * 5, 40) │
  │  score += boost                              │
  │                                              │
  │  < item.stock === 0 >    → score -= 50       │
  └──────────────────────────────────────────────┘
          |
          v
  [Filter: remove items with score <= 0 (if query set)]
          |
          v
  [Sort by score descending]
          |
          v
  [Render ranked item list]
          |
          v
  < Item has prediction > 1? >
          |              |
         YES             NO
          |              |
          v              v
  [Show "🤖 usually ×N"  [No badge shown]
   badge on item]

15. ERROR HANDLING FLOW
================================================================================

  [Any operation fails]
          |
          v
  ┌───────────────────────────────────────────────────────┐
  │                  ERROR TYPE?                          │
  │                                                       │
  │  Frontend Validation Error                            │
  │  → Show inline field error message                    │
  │  → Do NOT send to backend                             │
  │                                                       │
  │  Network Error (no connection)                        │
  │  → Axios catches error                                │
  │  → Show "Checkout failed. Please try again."          │
  │                                                       │
  │  400 Bad Request (empty cart)                         │
  │  → Show "Your cart is empty" message                  │
  │                                                       │
  │  404 Not Found (item deleted mid-session)             │
  │  → Show item not found error                          │
  │                                                       │
  │  409 Conflict (duplicate name / stock conflict)       │
  │  → Show specific conflict message                     │
  │  → e.g. "Only 3 in stock, you requested 10"          │
  │                                                       │
  │  422 Validation Error (bad data shape)                │
  │  → Show first validation error message                │
  │                                                       │
  │  500 Internal Server Error                            │
  │  → Show generic "unexpected error" (no stack trace)   │
  │  → Stack trace logged server-side only                │
  └───────────────────────────────────────────────────────┘
          |
          v
  [User sees friendly error message]
  [App remains functional — no crash]
  [User can retry the operation]
